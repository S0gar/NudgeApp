## Требования

## Зависимости
Для установки зависимостей, выполните команду:
```sh
cd path/to/project
python -m venv venv
venv\Scripts\activate.bat
pip install -r requirements.txt
```

## Файлы
config.example.ini - шаблон конфига. Для работы программы переименовать в config.ini и заполнить необходимые параметры
